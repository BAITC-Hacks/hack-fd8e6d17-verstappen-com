# AI Sana — рейтинг качества бизнес-задач и открытый выбор команд

MVP для кейса HackAlem AI. Представитель бизнеса превращает черновик задачи в полноценную карточку, система оценивает её готовность (0–100) и публикует в открытом каталоге. Студенческие команды сами выбирают задачи и откликаются, бизнес вручную выбирает команду.

**Сквозной сценарий:** черновик → уточняющие вопросы → карточка → рейтинг → каталог → отклик команды → выбор бизнеса → очки команде за подтверждённый этап.

## Запуск

Нужны Python 3.11+ и Node.js 18+.

```bash
./run.sh            # бэкенд :8000 + фронт :5173
./run.sh --reset    # то же, но БД пересоздаётся с тестовыми данными
```

Или через Docker:

```bash
docker compose up --build
```

- Фронт: http://localhost:5173
- API и Swagger: http://localhost:8000/docs
- Настройки: скопируйте `.env.example` в `backend/.env`. Без `OPENAI_API_KEY` работает заглушка (`mode: "mock"`).
- Для PostgreSQL можно указать `postgresql+asyncpg://...`: приложение использует синхронные SQLModel-сессии и автоматически переключает URL на драйвер psycopg.

**Проверить всё одной командой** (зависимости, тесты, сборка, смоук-тест сценария на изолированной копии с временной БД):

```bash
./check.sh           # полная проверка, ~30 секунд
./check.sh --quick   # без запуска серверов
```

Только тесты бэкенда:

```bash
cd backend && .venv/Scripts/python -m pytest   # Windows
cd backend && .venv/bin/python -m pytest       # macOS/Linux
```

## Архитектура

```
React + Vite (корень репо)  ──/api──►  FastAPI (backend/app)  ──►  SQLite (backend/data/app.db)
                                           │
                                           ├─ ai.py       анализ черновика, вопросы, сборка карточки (LLM + заглушка)
                                           ├─ scoring.py  формула рейтинга 0–100
                                           ├─ crud.py     пересчёт, правила каталога
                                           └─ routers/    ai, tasks, proposals, teams
```

**Фронт (hash-маршруты):** `#/` — лендинг, `#/team` — рабочее место команды (каталог, рекомендации, мои отклики, лидерборд), `#/business` — рабочее место бизнеса. Клиент API с типами — `src/api.ts`.

| Файл | Назначение |
|---|---|
| `backend/app/schemas.py` | Контракт API: карточка из 10 полей, рейтинг, задачи, отклики |
| `backend/app/models.py` | Таблицы `Task`, `Team`, `Proposal` |
| `backend/app/seed_data.json` | Синтетические данные: 5 черновиков, 8 карточек, 6 команд, 6 откликов |

## Формула рейтинга задачи

Баллы начисляются **только за заполненные и подтверждённые человеком поля**. Поле, которое человек отредактировал, считается подтверждённым.

| Показатель | Вес | Поля карточки |
|---|---|---|
| Контекст и потребность | 20 | `context` (10) + `need` (10) |
| Данные и материалы | 20 | `data` |
| Ожидаемый результат | 15 | `expected_result` |
| Критерии успеха | 15 | `success_criteria` |
| Ограничения | 10 | `constraints` |
| Пользователи | 10 | `users` |
| Связь с бизнесом | 10 | `contact` (5) + `interaction_format` (5) |

Название (`title`) обязательно для публикации, но баллов не даёт.

**Качество поля**, а не только заполненность:
- пустое поле — 0%;
- короче 15 символов — 50% («слишком кратко»);
- критерии успеха без числа или процента — 60%;
- ограничения без срока или объёма — 70%;
- контакт без email, телефона или Telegram — 50%.

Каждый показатель возвращается с пояснением, а подсказки отсортированы по тому, сколько баллов они добавят.

**Уровни готовности:**

| Баллы | Уровень | Что значит |
|---|---|---|
| 0–39 | Черновик | Видна в каталоге с пометкой «требует уточнения» |
| 40–69 | Рабочая | Можно откликаться, система может рекомендовать |
| 70–89 | Готовая | Повышенная позиция в каталоге |
| 90–100 | Приоритетная | Полностью готова, выделяется в каталоге |

После каждой правки рейтинг пересчитывается, а в `score_history` сохраняется история изменений.

## Правила каталога

1. Все опубликованные задачи видны всем командам. Низкий рейтинг не скрывает задачу и не запрещает отклик.
2. Сортировка: закрытые задачи внизу → по рейтингу по убыванию → при равном рейтинге сначала свежие → затем меньше откликов.
3. Фильтры: тема, уровень готовности, статус, поиск по тексту.
4. Рекомендации: только открытые задачи с рейтингом 40+, совпадение навыков, интересов и технологий команды с темой и тегами задачи. Причина показывается («Совпало: NLP, Python»). Персональные признаки не используются, каталог рекомендациями не ограничивается.
5. Число откликов не ограничено. Отклики не принимаются только у закрытой задачи.
6. Команду выбирает только бизнес вручную: одну, несколько или ни одной. Автоматического назначения нет.
7. Статусы задачи: `open` → `in_progress` (выбрана хотя бы одна команда) → `closed`.
8. За каждый подтверждённый бизнесом этап выбранная команда получает 20 очков в общий рейтинг команд.

## ИИ

Файл `backend/app/ai.py`. Используется официальный клиент OpenAI и модель из `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`) со Structured Outputs по Pydantic-схеме. После трёх неудачных попыток анализа включается заглушка на правилах. Правила:
- ИИ не добавляет фактов: у каждого заполненного поля есть `sources[field]` — точная цитата-подстрока исходного текста или соответствующего ответа пользователя. Поле без валидной цитаты обнуляется.
- Текст карточки редактируется и подтверждается человеком до публикации.
- Ответ модели проверяется Pydantic-схемой. При ошибке делается повтор, затем включается заглушка на правилах (`mode: "mock"` в ответе).

## Тестовые сценарии

Автотесты в `backend/tests/test_api.py`:

1. **Сквозной сценарий.** Слабый черновик → ≥3 вопроса → карточка с источниками → рост рейтинга → публикация → отклик → ручной выбор → этап → очки команде.
2. **Правка карточки** повышает рейтинг и позицию в каталоге, история рейтинга растёт.
3. **Неподтверждённые поля** не дают баллов.
4. **Каталог** показывает черновики и отсортирован по рейтингу.
5. **Задача с низким рейтингом** принимает отклики, но не попадает в рекомендации.
6. **Рекомендации** объясняют совпадение.
7. **Валидация:** короткий черновик, неверная ссылка, неизвестное поле → 422.
8. **Решение по отклику** окончательное. Закрытая задача не принимает отклики.

**Демо на 5 минут:**
- `./run.sh --reset`;
- черновик «Абитуриенты задают одни и те же вопросы…» (рейтинг 10);
- ответы на вопросы → рейтинг растёт до 70+;
- публикация;
- переключение на роль команды BotFactory → отклик;
- переключение на бизнес → «Выбрать» → «Этап подтверждён».
